# Загрузка фотографий iNaturalist
Программа для загрузки фотографий растений с iNaturalist и сохранения информации о наблюдениях в Excel.

Возможности:
- Загрузка и сортировка фотографий.
- Сбор информации об авторах, лицензиях и местах съёмки.
- Сохранение данных в Excel.
- Продолжение обработки с сохранённого прогресса.
- Заполнение пропущенных данных.
